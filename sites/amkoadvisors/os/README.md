# Official Statement PDFs

Put final Official Statement PDFs in this folder and register each one in
`../data/official-statements.js` (set `file` to `os/<filename>.pdf`).

Suggested filename pattern: `<issuer-slug>-<series>-os.pdf`, e.g.
`newtown-2026a-os.pdf`.

Keep each file under 25 MB so GitHub Pages serves it comfortably.
